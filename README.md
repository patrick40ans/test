## User Login Feature

A simple client-side user login page built with HTML, CSS, and JavaScript.

### Files

| File | Description |
|------|-------------|
| `index.html` | Login page markup |
| `style.css` | Styles for the login form |
| `app.js` | Client-side validation and simulated authentication logic |

### Usage

Open `index.html` in a browser. Use the demo credentials below to log in:

| Field | Value |
|-------|-------|
| Username | `admin` |
| Password | `D3m0P@ssw0rd!` |

> **Note:** This implementation is a front-end demo only. In a production application, authentication must be handled server-side with secure password hashing, HTTPS, and proper session management.
